# Global 20% UI Scale — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make the entire TrueHire UI render ~20% larger, proportionally, by scaling every window's content and box in one place.

**Architecture:** A single `$Script:UiScale = 1.2` constant in `lib/Theme.ps1` drives a new `Set-WindowUiScale` helper. `ConvertTo-Window` — the one chokepoint every view and dialog passes through — calls it to (1) apply a `ScaleTransform` as the root element's `LayoutTransform` and (2) grow the window's `Width`/`Height`/`MinWidth`/`MinHeight` by the same factor, clamped to the primary monitor work area. Scaling both content and box keeps today's layout identical, just magnified. No view XAML changes.

**Tech Stack:** Windows PowerShell 5.1 + WPF (XAML loaded via `XamlReader`). No unit-test framework — the regression gate is the end-to-end `test\smoke.ps1`, extended here with scale assertions. Spec: `docs/superpowers/specs/2026-06-01-ui-20pct-scale-design.md`.

**Branch:** `upgrades` (already checked out).

- [ ] **Step 2: Add the `Set-WindowUiScale` function**

In `lib/Theme.ps1`, insert this function immediately **before** `function ConvertTo-Window {` (line 410):

```powershell
function Set-WindowUiScale {
    <#
    Magnifies a window's entire visual tree by $Script:UiScale and grows the
    window box by the same factor, so the on-screen layout is identical to 1.0x
    just rendered larger. The window box is clamped to the primary monitor work
    area so a scaled window never opens partly off-screen. Called by
    ConvertTo-Window before the window is shown. No-op when UiScale is unset/<=0/1.

    Note: the clamp uses the PRIMARY monitor work area; a dialog opened on a
    smaller secondary monitor may clamp looser than ideal. Acceptable here.
    #>
    param([System.Windows.Window]$Window)
    if (-not $Window) { return }
    $scale = $Script:UiScale
    if (-not $scale -or $scale -le 0 -or $scale -eq 1) { return }

    # 1) Scale the content visual tree via a LayoutTransform on the root element.
    $root = $Window.Content
    if ($root -is [System.Windows.FrameworkElement]) {
        $root.LayoutTransform = New-Object System.Windows.Media.ScaleTransform($scale, $scale)
    }

    # 2) Grow the window box to match, clamped to the work area. Guard NaN/auto/0.
    $wa = [System.Windows.SystemParameters]::WorkArea
    $maxW = if ($wa.Width  -gt 0) { [double]$wa.Width }  else { [double]::PositiveInfinity }
    $maxH = if ($wa.Height -gt 0) { [double]$wa.Height } else { [double]::PositiveInfinity }

    $dims = @(
        @{ Prop = 'Width';     Max = $maxW },
        @{ Prop = 'Height';    Max = $maxH },
        @{ Prop = 'MinWidth';  Max = $maxW },
        @{ Prop = 'MinHeight'; Max = $maxH },
        @{ Prop = 'MaxWidth';  Max = [double]::PositiveInfinity },
        @{ Prop = 'MaxHeight'; Max = [double]::PositiveInfinity }
    )
    foreach ($d in $dims) {
        $cur = $Window.($d.Prop)
        if ($null -ne $cur -and
            -not [double]::IsNaN($cur) -and
            -not [double]::IsInfinity($cur) -and
            $cur -gt 0) {
            $Window.($d.Prop) = [Math]::Min($cur * $scale, $d.Max)
        }
    }
}
```
